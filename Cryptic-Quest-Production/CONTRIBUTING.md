# Contributing

1. Create a branch from `main`.
2. Keep runtime dependencies at zero unless a dependency provides clear educational value that cannot be achieved safely with platform APIs.
3. Run `npm run check` before opening a pull request.
4. Add regression tests for new mathematical/cryptographic utilities.
5. Keep teaching examples clearly labeled when they are intentionally insecure or use toy parameters.
6. Preserve keyboard accessibility, readable focus states, responsive layouts, and reduced-motion behavior.
7. Do not add analytics or learner-data transmission without an explicit privacy/design review and corresponding documentation.
